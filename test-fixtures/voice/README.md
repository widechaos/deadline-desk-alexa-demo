# Synthetic voice fixtures

These six English WAV files were synthesized for Deadline Desk from the test requests in scripts/eval-voice.mjs. They are not recordings of a user or a claim of human microphone quality.

- Model: Kokoro v1.0, af_sarah preset, Apache-2.0 — https://huggingface.co/hexgrad/Kokoro-82M
- Runtime: kokoro-onnx, MIT — https://github.com/thewh1teagle/kokoro-onnx
- Public demo-request.wav is a 16 kHz mono conversion of 0.wav.
- No model weights are bundled. No custom voice clone was used.
